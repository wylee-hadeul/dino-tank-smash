# 🦖 공룡 대난동 vs 탱크 군단

Godot 4.6로 만든 공룡이 탱크를 부수는 2D 액션 게임. 모바일 웹(가로 모드)과 데스크톱 모두 지원.

**플레이:** https://wylee-hadeul.github.io/dino-tank-smash/

## 조작
| 동작 | 키보드 | 모바일 |
|---|---|---|
| 이동 | A/D, ←/→ | ◀ ▶ |
| 점프 (탱크 밟기) | W, Space, ↑ | JUMP |
| 물기 (포탄 받아치기) | J, Z, F | BITE |
| 포효 (게이지 100%) | K, X, E | ROAR |

- 날아오는 포탄을 물면 적에게 되돌려 보낸다 (3배 데미지)
- 연속 처치 시 콤보 배수 (최대 x5)

## 스테이지
- 로비에서 스테이지를 골라 출격. 스테이지마다 **웨이브 3개, 마지막은 보스전**. 클리어하면 다음 스테이지 해금 (끝없이 계속됨)
- 스테이지가 오를수록 적 체력(+20%/스테이지)·공격력(+10%)·연사력·적 수·동시 출현 수 증가
- 테마 순환: 초원 → 노을 → 밤 → 화산 지대
- 웨이브 클리어 시 **강화 카드** 선택 (11종, 해당 스테이지 동안 유지)

## 적
| 적 | 첫 등장 | 특징 |
|---|---|---|
| 경전차 / 중형 전차 | 1 | 거리를 두고 포격 |
| 돌격 지프 | 2 | 빠르게 들이받고 후퇴 |
| 공격 헬기 | 3 | 위에서 폭탄 투하. 점프해서 물기 |
| 중전차 / 로켓 트럭 | 4 | 강한 포탄 / 멀리서 로켓 3연발 |
| 자폭 드론 | 5 | 조준 후 급강하 자폭 |
| 장갑 전차 | 6 | 물기 피해 65% 감소, 밟기 2배 |
| 폭격기 | 7 | 경고 후 머리 위를 지나가며 폭격 |

## 보스 (스테이지마다 순환, 체력 절반 이하에서 분노)
- **기가 탱크**: 산탄 포격 / 기관총 / 돌진 → 벽에 부딪혀 기절하면 추가 피해 기회
- **하늘 요새**: 융단 폭격 / 미사일 / 드론 소환 / 저공 비행(물기 기회)
- **아이언 렉스**: 레이저 / 지진파(점프로 회피) / 미사일 / 근접 물기

## 아웃게임 강화 (골드)
적 처치·보스·스테이지 클리어로 골드 획득 → 로비의 **강화 상점**에서 영구 강화:
체력 단련, 이빨 연마, 강철 비늘, 포효 수련, 순발력, 황금 발톱(골드 +15%), 행운(카드 선택지 +1), 불사조 심장(스테이지당 1회 부활)

포효로 준 피해와 처치로는 포효 게이지가 차지 않는다.

## 개발
```bash
godot --path .                                   # 실행
godot --path . -- --autoplay --shots=/tmp/shots --duration=60   # 오토플레이 봇 + 스크린샷/로그
#   옵션: --stage=N --gold=N --god --fresh --suicide=SEC --manualpick --shot-every=SEC
./tools/export_web.sh   # 웹 빌드 + 캐시 무효화 (GitHub Pages: main /docs)
```
웹 빌드에서도 `index.html?autoplay&stage=3&god` 처럼 봇 플레이 가능. 오토플레이는 별도 저장 파일(`save_autoplay.cfg`)을 써서 실제 진행에 영향이 없다.
